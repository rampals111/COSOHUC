A deterministic COSOHUC heuristic for K-means cluster initialization, compared with Farthest First, Canopy, K-Means++, Hartigan-Wong, MacQueen, Lloyd, Forgy, ECKM, and Mini-Batch K-Means++ using benchmark, feature-correlation, scalability, and result-analysis experiments.
Result-Analysis Procedures
The result-analysis procedures include the calculation, aggregation, and presentation of experimental results reported in the manuscript. For the benchmark and feature-correlation experiments, each condition is evaluated over 40 independent runs, and the results are summarized using mean ± standard deviation (SD). The clustering measures include BSS, TWSS, Density, Dunn Index (DI), Davies–Bouldin Index (DBI), Silhouette Index (SI), Rand Index (RI), and convergence iterations. For lower-is-better measures, the minimum value is considered preferable, whereas for higher-is-better measures, the maximum value is considered preferable. Tables 2–13 report the benchmark results for six real-world numerical datasets with K = 3 and K = 4. Tables 14–17 report the feature-correlation sensitivity results for seven target correlation levels and four synthetic-data configurations. For the scalability experiment, 10 independent runs with three timing repetitions per run are used, and initialization time, total K-means execution time, peak memory usage, and convergence iterations are summarized as mean ± SD in Table 18. The analysis emphasizes comparative performance and consistency across datasets and experimental conditions rather than treating the evaluation measures as statistically independent votes.
